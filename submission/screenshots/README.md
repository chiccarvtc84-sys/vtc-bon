# Screenshots stores — TrajetPro

Générés le 2026-07-05 depuis la nouvelle UI (« TrajetPro Clair », accent bleu),
via captures pleine résolution de l'app réelle (données de démonstration :
course Sorgues → Gare Avignon TGV, client « M. Laurent »).

## ios/ — App Store Connect (1290 × 2796, iPhone 6,7")

À téléverser dans App Store Connect → fiche app → « Captures d'écran iPhone ».
Apple accepte le format 6,7" pour toutes les tailles d'iPhone.
Ordre conseillé sur la fiche (le 1er est le plus vu) :

1. `01-accueil.png` — carte réelle + prochaine course + ETA (l'écran signature)
2. `02-en-route.png` — suivi GPS live, km/min restants, « Je suis arrivé »
3. `03-nouvelle-course.png` — création de bon : trajet A→B + grand montant
4. `04-facture.png` — facture conforme (Total TTC, encaissement, envoi PDF/WhatsApp)
5. `05-factures.png` — liste factures + totaux Encaissé / En attente
6. `06-jetons.png` — solde crédits + achat
7. `07-welcome.png` — écran d'accueil avec le logo

## android/ — Google Play Console (1080 × 2400)

Play Console → Fiche du Play Store → « Captures d'écran pour téléphone »
(minimum 2, jusqu'à 8). Mêmes écrans 01 → 06.

`feature-graphic.png` (1024 × 500) — « Image de présentation » obligatoire,
à téléverser dans la même section.
